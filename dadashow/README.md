## 🚀 Vercel ilə Pulsuz Canlı Link Almaq (Deployment)

Bu layihə **100% Vercel və Netlify ilə tam uyğundur** (heç bir əlavə server sazlaması tələb olunmur).

### Seçim 1: GitHub vasitəsilə Vercel-ə yükləmək (Tövsiyə olunan)
1. Bu qovluğu GitHub-da yeni bir repository-ə yükləyin (`git push`).
2. [vercel.com](https://vercel.com) saytına daxil olun.
3. **"Add New Project"** düyməsinə basın və həmin repository-ni seçin.
4. **"Deploy"** düyməsinə klikləyin. 15 saniyə ərzində sizə pulsuz `https://dadashow-memory-game.vercel.app` canlı linki veriləcək!

### Seçim 2: Vercel CLI ilə birbaşa terminaldan
1. Əgər Node.js və ya Vercel CLI varsa:
   ```bash
   npx vercel
   ```
2. Sorğulara `Enter` basaraq təsdiqləyin, linkiniz dərhal hazır olacaq.

### Seçim 3: Netlify Drop ilə (Kod yazmadan, ən asan)
1. [app.netlify.com/drop](https://app.netlify.com/drop) saytını açın.
2. Bu qovluğu (və ya `.zip` faylını) birbaşa ora sürüşdürüb atın (Drag & Drop).
3. 5 saniyə sonra hər kəslə paylaşa biləcəyiniz canlı veb linkiniz hazır olacaq!
